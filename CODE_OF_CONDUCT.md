# Code of Conduct

Changes AI contributors and users are expected to keep project communication
professional, respectful, and focused on the work.

## Expected Behavior

- Be direct and constructive.
- Assume good intent unless there is clear evidence otherwise.
- Keep technical criticism specific and actionable.
- Respect privacy when discussing security reports, private repositories,
  source-derived usage data, API keys, and vulnerability details.
- Accept maintainer decisions about scope, release risk, and project direction.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private security details, secrets, or source snippets without
  permission.
- Repeated off-topic or disruptive comments.
- Deliberately misleading vulnerability claims or fabricated evidence.
- Using project spaces to pressure maintainers or contributors outside the
  scope of the project.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests;
temporarily restrict participation; or permanently block users when behavior
harms the project or its contributors.

Security-sensitive incidents may be handled privately to protect users and
affected systems.

## Reporting

Report conduct concerns to the repository maintainer. If the concern involves a
security issue, follow `SECURITY.md` and avoid posting sensitive details in
public.
